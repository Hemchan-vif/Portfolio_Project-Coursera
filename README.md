# Portfolio Website (Coursera Demo Project)

This repository contains a simple portfolio website created as part of a Coursera course assignment.

## Project Purpose
This is a beginner-level demo project designed to demonstrate:
- HTML structure
- CSS styling and responsiveness
- JavaScript interactivity
- Accessibility basics
- Deployment using GitHub Pages

## Technologies Used
- HTML
- CSS
- JavaScript
